# AGENTS.md Wizard

Interactive config generator for AI coding agents. Generate production-ready `CLAUDE.md`, `AGENTS.md`, and `.cursorrules` files through a step-by-step wizard.

## Features

- **Step-by-step wizard** — walks you through stack, style, behavior, and tooling preferences
- **Multi-format output** — generates CLAUDE.md, AGENTS.md, and .cursorrules files
- **Community templates** — pre-built configs for TypeScript, Python, Go, Rust, Swift, Ruby, and more
- **Draft auto-save** — localStorage saves your progress automatically
- **Zero backend** — everything runs in your browser, nothing is sent anywhere

## Usage

Open `index.html` in your browser. That's it.

Or visit: [ianhandy.com/agents-md-wizard](https://ianhandy.com/agents-md-wizard)

## Supported Agents

- Claude Code
- Cursor
- Cline
- Windsurf
- GitHub Copilot
- Aider

## Stack

Single HTML file. No dependencies. No build tools. No framework.
